ABOUT BOOKSPHERE

A smarter way to explore books.

BookSphere is a responsive digital library interface created for students to discover, filter, save and explore books from different categories.

This project demonstrates HTML5, CSS3, Bootstrap, JavaScript, responsive design and basic client-side data persistence.
