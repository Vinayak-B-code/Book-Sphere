# BookSphere - Smart Online Book Explorer

## Files
- index.html - main webpage
- css/style.css - custom styling and responsive design
- js/script.js - search, filtering, favorites, modal, dark mode, recommendations, surprise book, form validation
- images/ - optional folder for local images

## Run
Open index.html in a browser.

## Features
- Bootstrap navbar, cards, dropdown, forms, badges, modal and toast
- 6 books
- Live search
- Category filtering
- Sorting
- Favorites using localStorage
- Book details modal
- Ratings
- Availability badges
- Dark/light mode using localStorage
- Surprise Me random book
- Trending books
- Rule-based recommendations
- Registration form validation
- Responsive layout

Book cover images are loaded from Open Library cover URLs in JavaScript. An internet connection is needed for those covers.
